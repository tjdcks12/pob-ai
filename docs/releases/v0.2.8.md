# PoB AI v0.2.8

## 한국어

- 캐릭터 자동 갱신 토글이 요청 처리 중 다시 꺼지거나, 실패 후 조작할 수 없던 문제를 수정했습니다.
- 상태를 다시 읽을 때 캐릭터·갱신 주기 메뉴를 불필요하게 다시 만들지 않도록 수정해, 메뉴 깜빡임과 선택값 초기화를 방지했습니다.
- PoB에 미저장 편집이 있어도 자동 갱신을 켤 수 있습니다. 실제 가져오기와 저장은 사용자가 PoB에서 편집을 저장할 때까지 대기합니다. 저장 후 설정한 주기 또는 ‘지금 갱신’으로 계속할 수 있습니다.
- 기존 설정, 대화 기록, PoB의 미저장 편집을 유지합니다. 자동 갱신은 기본적으로 꺼져 있습니다.

기존 사용자는 설정의 업데이트를 내려받고 적용하세요. 새 ZIP을 실행해도 구버전 화면이 계속 보이면 실행 중인 PoB AI에서 업데이트를 적용해 서비스를 다시 시작하세요.

## English

- Fixed the automatic character refresh switch reverting while a request was pending and controls remaining disabled after a failed request.
- Kept character and interval menus stable during status reloads, preserving selections and avoiding unnecessary menu redraws.
- Automatic refresh can now be enabled while PoB has unsaved edits. Importing and saving remain paused until you save those edits in PoB. Refresh then resumes at the selected interval or through Refresh now.
- Preserves settings, chat history and unsaved PoB edits. Automatic character refresh remains off by default.

Existing users can download and apply the update in Settings. If opening the new ZIP still shows an older running version, apply the update from the running PoB AI to restart its service.
