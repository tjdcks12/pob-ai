# PoB AI v0.2.13

## 한국어

- 캐릭터 자동 갱신이 매번 캐릭터 목록까지 새로 내려받아, ‘캐릭터 목록 새로 고침’과 함께 쓰면 Path of Exile API 요청 제한에 쉽게 걸리던 문제를 수정했습니다. 이제 이미 받은 목록을 재사용하고, 목록에 캐릭터가 없을 때만 다시 내려받습니다.
- 요청 제한에 걸리면 PoB 가져오기 탭이 처음 단계로 돌아가 로그인이 풀린 것처럼 보이던 문제를 수정했습니다. 이제 이미 받은 캐릭터 목록 화면을 유지합니다.
- ‘캐릭터 목록 새로 고침’이 제한에 걸려도 설정의 캐릭터 목록을 비우지 않고, 잠시 기다려 달라는 안내를 표시합니다. 자동 갱신은 다음 주기에 다시 시도합니다.

**이전 버전에서 업데이트할 때:** 업데이트를 적용한 뒤 PoB에 열린 빌드를 저장하고 PoB 창을 닫은 다음, PoB AI로 다시 열어 주세요. 이번 수정은 PoB를 다시 열어야 적용됩니다. 앱이 미저장 편집을 강제로 저장하거나 PoB 창을 강제로 닫지는 않습니다.

## English

- Fixed automatic character refresh downloading the character list on every run, which quickly hit Path of Exile's API rate limit when combined with Reload characters. Refresh now reuses the loaded list and downloads it only when the character is missing.
- Fixed a rate-limited request sending PoB's Import tab back to its first step, which looked like a sign-out. PoB now stays on the loaded character list.
- A rate-limited Reload characters keeps the characters in Settings and asks you to wait a moment. Automatic refresh retries at the next interval.

**When upgrading:** after applying the update, save your open build in PoB, close the PoB window, and reopen it through PoB AI. This fix takes effect once PoB is reopened. The app does not force-save unsaved edits or force-close PoB.
