# PoB AI v0.2.7

- Optional automatic character refresh updates passives, jewels, equipment and skills in the open PoB build and saves the same XML file. The default is off; choose a 1, 2, 5 or 10 minute interval in Settings.
- Preserves main-skill identity and calculation settings, pauses on unsaved edits and restores the previous build on import or save failures.
- Includes the red application icon, clearer PoB buttons, dock/undock toggle and all automatic download/restart improvements from v0.2.6.
- Works with poe2way desktop’s optional shared-file watcher so its build and item comparison can follow the same saved XML.
