# PoB AI v0.2.18

## 한국어

- 캐릭터 주기 새로고침이 "저장되지 않은 변경"으로 계속 멈춰 있던 문제를 고쳤습니다. 패시브 트리 검색창에 글자가 남아 있기만 해도 PoB가 빌드를 수정된 것으로 표시해서, 아이템·스킬·패시브 트리·주얼을 가져오지도 저장하지도 못했습니다. 이제 실제로 편집한 내용이 있을 때만 멈춥니다.

## English

- Periodic character refresh no longer stays paused as "unsaved". PoB marked the build as modified whenever text sat in the passive tree search box, so items, skills, the passive tree and jewels were never imported or saved. Refresh now pauses only for real edits.
