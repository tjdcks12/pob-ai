# PoB AI v0.2.9

## 한국어

- 패널 붙이기를 켜면 AI 채팅이 PoB 창의 오른쪽 내부 영역에 들어갑니다. PoB와 제목줄을 공유하고, 경계선을 끌어 패널 너비를 조절할 수 있습니다. 붙이기를 끄면 기존 독립 창 위치로 돌아갑니다.
- PoB 크기 변경, 최소화·복원, 정상 종료와 비정상 종료 시 패널 연결과 분리를 처리합니다. 설정 창은 별도 창으로 유지합니다.
- 새 ZIP을 실행해도 구버전 서비스와 화면을 그대로 재사용하던 문제를 수정했습니다. 구버전이 실행 중이면 기존의 검증된 업데이트 절차로 전환합니다. AI 응답이나 캐릭터 갱신이 진행 중이면 업데이트만 준비하고 재시작을 보류합니다.
- 0.2.8의 자동 갱신 토글·메뉴 깜빡임 수정도 포함합니다.

**이전 버전에서 업데이트할 때:** PoB에 열린 빌드를 직접 저장하고 PoB 창을 닫은 다음, 업데이트한 PoB AI로 다시 열어 주세요. 내부 패널에 필요한 PoB 연결 코드가 이때 적용됩니다. 앱이 미저장 편집을 강제로 저장하거나 PoB 창을 강제로 닫지는 않습니다.

## English

- Docked AI chat now occupies a reserved area inside the right side of the PoB window and shares its title bar. Drag the divider to resize it; undocking restores the independent window's placement.
- Handles owner resizing, minimizing/restoring, graceful exit and crashes. Settings remains a separate window.
- Fixed a newly launched release silently reusing an older running service and UI. It now uses the existing verified update flow. Active AI turns or character imports defer the restart while preparing the update.
- Includes the automatic character refresh switch and menu stability fixes from 0.2.8.

**When upgrading:** save your open build in PoB, close the PoB window, and reopen it through the updated PoB AI. This loads the connection code needed for the embedded panel. The app does not force-save unsaved edits or force-close PoB.
