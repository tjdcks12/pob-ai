# PoB AI v0.2.14

## 한국어

- 업데이트를 설치한 뒤 예전 버전 폴더를 정리하다가, 아직 사용 중인 파일 때문에 업데이트 전체가 실패한 것처럼 표시되던 문제를 수정했습니다. 사용 중인 폴더는 건너뛰고 다음 업데이트 때 정리합니다.
- 캐릭터 정보가 바뀌지 않아 자동 갱신이 가져오기를 건너뛸 때, PoB 가져오기 탭에 “Retrieving character data...”가 계속 남던 문제를 수정했습니다. 이제 다운로드 전에 보이던 문구로 돌아갑니다.

**이전 버전에서 업데이트할 때:** 업데이트를 적용한 뒤 PoB에 열린 빌드를 저장하고 PoB 창을 닫은 다음, PoB AI로 다시 열어 주세요. 가져오기 탭 문구 수정은 PoB를 다시 열어야 적용됩니다. 0.2.13 이하에서 업데이트할 때 예전 폴더 정리 오류가 한 번 더 표시될 수 있지만, 새 버전은 정상 설치됩니다. PoB AI를 다시 시작하면 새 버전이 실행됩니다.

## English

- Fixed an installed update reporting failure when an older version folder was still in use during cleanup. Folders in use are now skipped and removed by a later update.
- Fixed PoB's Import tab staying on “Retrieving character data...” when an unchanged character refresh skips the import. It now returns to the message shown before the download.

**When upgrading:** after applying the update, save your open build in PoB, close the PoB window, and reopen it through PoB AI. The Import tab fix takes effect once PoB is reopened. Updating from 0.2.13 or earlier may still show the old-folder cleanup error once, but the new version is installed; restarting PoB AI runs it.
